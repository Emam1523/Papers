## Research direction (provisional)
An **assurance report** for AI-agent patches: separate signals (no single weighted score), each with uncertainty and tool/model version. Static signal = reasoning judge (RePaCA-like). Dynamic signals = environment setup, regression tests, patch-targeted tests, distinguishing tests between candidate patches, oracle-strength audit. Also leakage check (.git/network), security scan, run consistency (pass^k), "could not verify" as an explicit outcome. Evaluate on fresh SWE-rebench tasks + corrected SWE-Bench Pro Verified subset, multiple runs, paired tests (McNemar), recall AND specificity.
